工具发布包包含未经修改的小赖字体 font.ttf，并在 Release 提供单独下载。
外置字体模式读取游戏 EXE 同目录的 font.otf / font.ttf，否则回退系统字体。
字体仅注册在游戏进程中，不安装到 Windows；外置模式不内嵌字体。
The tools release includes the unmodified default Xiaolai font as font.ttf,
also available as a separate Release asset. External mode tries
font.otf then font.ttf beside the game EXE, falling back to the system font.
Fonts are registered privately in the game process, not installed in Windows.
